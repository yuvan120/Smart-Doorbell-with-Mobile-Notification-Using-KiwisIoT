# Smart-Doorbell-with-Mobile-Notification-Using-KiwisIoT
An ESP32-powered smart doorbell that detects visitors and sends instant mobile notifications through the KiwisIoT Dashboard.

## 📌 About the Project

Smart Doorbell with Mobile Notification Using KiwisIoT is an IoT-based smart home project designed to notify homeowners whenever someone presses the doorbell.

Using an ESP32 microcontroller and a push-button switch, the system detects when a visitor presses the doorbell. The event is transmitted through Wi-Fi to the KiwisIoT platform.

Users can monitor doorbell activity through the KiwisIoT dashboard and receive mobile notifications when someone rings the doorbell, helping them stay informed even when they are away from home.

This project demonstrates how IoT technology can improve home convenience, enable remote visitor notifications, and support smart home automation.
